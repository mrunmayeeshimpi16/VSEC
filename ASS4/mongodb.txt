MongoDB Operations - College Database

1. Switch to Database
use('college');
Output: switched to db college

2. Insert One Document
db.students.insertOne({
  name: "Vikram Singh",
  age: 22,
  marks: 72,
  department: "Computer Science",
  city: "Pune"
});
Output:

{
  acknowledged: true,
  insertedId: ObjectId('6a867a6a7c5a6121e91891b9')
}
